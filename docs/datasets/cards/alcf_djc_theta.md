# ALCF DJC — Theta (2017–2024)

`dataset.alcf_djc_theta` · version 1.0.0 · system Theta · serves job runtime

> Generated by `hpc-oda datasets cards` from the dataset's descriptor, its runtime card, the error ceilings, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_dataset_cards.py` fails when it differs from what the generator writes.

DIM_JOB_COMPOSITE job accounting from Argonne's Theta supercomputer (Cray XC40, Intel Knights Landing), 2017-07 through 2024 in eight files, from the ALCF public data catalog: Cobalt/PBS scheduler records with requested walltime (WALLTIME_SECONDS) and elapsed runtime (RUNTIME_SECONDS), cores and nodes used and requested, queue, exit status, machine, award category and science field. Users and projects are anonymized at source. Theta was decommissioned at the end of 2023, so the 2024 file is nearly empty. ALCF gates downloads behind a one-time name and email form, so fetch the files yourself; `datasets prepare --from <dir>` then checks and normalizes them (see docs/datasets/alcf-djc-ingest.md).
