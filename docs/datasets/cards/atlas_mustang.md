# Atlas Mustang (LANL)

`dataset.atlas_mustang` · version 1.0.0 · system Mustang · serves job runtime

> Generated by `hpc-oda datasets cards` from the dataset's descriptor, its runtime card, the error ceilings, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_dataset_cards.py` fails when it differs from what the generator writes.

Slurm trace of LANL's Mustang cluster from the Atlas repository (2.1M jobs, 2011–2016). Runtime is end_time − start_time, and requested walltime is wallclock_limit (a pandas timedelta string). Mustang has no job id column, so job_id is a row-index surrogate. Timestamps carry −06:00/−07:00 offsets and are normalized to UTC.
