Slurm trace of LANL's Trinity supercomputer (OpenTrinity) from the Atlas repository, formatted release (~25k jobs, February–April 2016; 21,531 have a runtime). Runtime is end_time − start_time, and requested walltime is wallclock_limit (a pandas timedelta string). There is no job id column, so job_id is a row-index surrogate. Timestamps carry −06:00/−07:00 offsets and are normalized to UTC.
