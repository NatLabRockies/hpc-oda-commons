# FRESCO Conte Job Accounting

`dataset.fresco_conte` · version 1.0.0 · system Conte · serves job runtime

> Generated by `hpc-oda datasets cards` from the dataset's descriptor, its runtime card, the error ceilings, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_dataset_cards.py` fails when it differs from what the generator writes.

Torque/PBS job accounting from Purdue's Conte cluster, from the FRESCO repository: the per-event accounting CSVs for 12 consecutive months, March 2015–February 2016. Only completed-job (E) records have a runtime, so those are the rows kept. Runtime is resources_used.walltime and requested walltime is Resource_List.walltime (seconds); timestamps are MM/DD/YYYY. Users and groups are anonymized at source.
