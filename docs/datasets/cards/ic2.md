# IC2 Integrated Cloud + HPC Jobs

`dataset.ic2` · version 1.0.0 · system IC2, Polaris, AWS · serves job runtime

> Generated by `hpc-oda datasets cards` from the dataset's descriptor, its runtime card, the error ceilings, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_dataset_cards.py` fails when it differs from what the generator writes.

Runtime and resource-utilization records of tasks run on integrated cloud and HPC platforms (IC2, ALCF Polaris and AWS), from "Predicting Runtime and Resource Utilization of Jobs on Integrated Cloud and HPC Systems". The nested workload JSON is flattened to one row per task, dropping the per-node metric arrays. Runtime is finish_time − start_time; timestamps are Unix epoch floats; there is no requested walltime. `platform` names the system.
