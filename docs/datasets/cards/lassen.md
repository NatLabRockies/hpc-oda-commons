# Lassen LAST (LLNL)

`dataset.lassen` · version 1.0.0 · system Lassen · serves job runtime

Per-job allocation history of LLNL's Lassen supercomputer (IBM CSM/LSF), 1,467,747 jobs, from the Livermore Archive for System Telemetry (LAST). Runtime is end_time − begin_time; requested walltime is time_limit in seconds, with the 2147483647 "unlimited" sentinel made null. Allocated nodes, CPUs and GPUs, queue and exit status are mapped; users and groups are hashed at source. Timestamps are naive and read as UTC. The file is tracked with git LFS on GitHub and fetched over plain HTTPS from its LFS media URL.
