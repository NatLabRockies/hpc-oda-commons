The slurmdbd scheduler log from the MIT SuperCloud Datacenter Challenge, 202201 release (a release tag, not a data month): about 396k jobs, January–October 2021, including GPU jobs. Only the 103 MB scheduler CSV is used, not the ~2 TB of node telemetry. Runtime is time_end − time_start; requested walltime is timelimit in minutes, with the 4294967295 "unlimited" sentinel made null. Timestamps are Unix epoch seconds; state is a numeric Slurm state code.
