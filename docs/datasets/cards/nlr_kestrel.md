# NLR Kestrel Jobs (anonymized)

`dataset.nlr_kestrel` · version 1.1.0 · system Kestrel · serves job runtime and job power

> Generated by `hpc-oda datasets cards` from the dataset's descriptor, its runtime card, the error ceilings, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_dataset_cards.py` fails when it differs from what the generator writes.

Anonymized Slurm sacct job records of NLR's Kestrel system (with H100 GPUs), August 2023–December 2025 (about 11M jobs), as a zipped Hive-partitioned Parquet dataset. Runtime is end_time − start_time; requested walltime is wallclock_req; timestamps are normalized to UTC. Users and accounts are hashed at source. Average power: consumed_energy_raw_joules is Slurm's job energy summed over its nodes, so whole-job watts are energy ÷ runtime (avgpcon) and per node that ÷ nodes_used (avgpcon_per_node). Only CPU nodes record energy. On a shared node Slurm reports the node's energy, not the job's, so power is null for a job that shared its node (shared_job_count ≥ 1, or a shared* partition). 0 J means no reading. Per-node values outside the 0.1st–99.9th percentiles become null.
