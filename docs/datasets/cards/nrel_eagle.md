# NREL Eagle Jobs (OEDI 5860)

`dataset.nrel_eagle` · version 1.0.0 · system Eagle · serves job runtime

Per-job Slurm accounting of NREL's Eagle supercomputer (OEDI submission 5860), about 11.03M jobs from 2018 through February 2023, in one parquet file. Runtime is run_time and requested walltime is wallclock_req (seconds). Requested nodes, processors and GPUs, partition, QOS and final job state are mapped.
