## How it runs

It is in the runtime fleet (`bench-matrix`), at training lookbacks of 10, 30, 120 days.

`hpc-oda benchmark` runs it with these `split.method` values:

### `fixed`

Runner: `run_fixed_baseline`. The recipe `split` keys it reads:

| Key | Default |
|---|---|
| `train_fraction` | `0.8` |

### `rolling`

Runner: `run_rolling_baseline`. The recipe `split` keys it reads:

| Key | Default |
|---|---|
| `n_windows` | `1000` |
| `test_window_hours` | `6` |
| `training_lookback_days` | `100` |
