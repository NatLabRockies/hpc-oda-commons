# Embedding + kNN

`model.job_runtime_embedding_knn` · version 0.1.0 · predicts job runtime and job power

> Generated by `hpc-oda models cards` from the code, the registry, the bundled recipes and the published leaderboard. Don't edit it by hand: `tests/unit/test_model_cards.py` fails when it differs from what the generator writes.

Precomputed dense embeddings of job metadata with similarity-weighted k-nearest-neighbor regression, for every rolling window. Predicts runtime or power.
